# Showhow

**프로그램을 평소처럼 사용하면, 그게 곧 매뉴얼이 됩니다.**

클릭할 때마다 자동으로 화면이 캡처되고 번호와 설명이 붙어 업무 매뉴얼이 만들어집니다.
브라우저뿐 아니라 PC의 모든 프로그램(사내 시스템 포함)에서 동작하며, 모든 데이터는 내 PC에만 저장됩니다.

제작: **blue_hacker_26**

## 다운로드

[**최신 버전 받기**](https://github.com/Heomooyoung/showhow/releases/latest)

| 파일 | 설명 |
|---|---|
| `Showhow-<버전>-Setup.exe` | **설치 프로그램 (권장)**. 관리자 권한 없이 내 계정에만 설치되고, 시작 메뉴·바탕 화면 바로 가기와 제거 항목이 만들어집니다. 편집기에 필요한 WebView2 런타임이 없으면 설치 중에 함께 받습니다. |
| `Showhow-<버전>-portable.zip` | 압축만 풀어 `Showhow.exe` 더블클릭. 설치 없이 USB에 넣어 다녀도 됩니다. |
| `SHA256SUMS.txt` | 받은 파일이 손상·변조되지 않았는지 확인하는 해시 |

> **Windows 10 / 11 (64비트) 전용**입니다. 저수준 마우스·키보드 훅, Windows UI Automation, WebView2를 쓰는
> 네이티브 프로그램이라 macOS·Linux에서는 실행되지 않습니다.

### 처음 실행할 때 경고가 뜬다면

코드 서명 인증서를 아직 붙이지 않아서 **"Windows의 PC 보호"** 창이 뜰 수 있습니다.
**추가 정보 → 실행**을 누르면 됩니다. 걱정되시면 위의 `SHA256SUMS.txt`와 받은 파일의 해시를 비교해 보세요.

```powershell
Get-FileHash .\Showhow-0.7.1-Setup.exe -Algorithm SHA256
```

## 사용법

1. **새 매뉴얼 녹화하기** → 제목 입력
2. 화면 위에 뜬 작은 툴바에서 **● 녹화 시작**
3. 매뉴얼로 만들 프로그램을 평소처럼 사용 (클릭할 때마다 자동 캡처 + 번호 + 설명 자동 생성)
   - ⏸ 일시정지(`Ctrl+Alt+P`): 기록에서 빼고 싶은 조작을 할 때
   - ↩ 마지막 동작 삭제: 방금 담긴 동작 하나만 지우기
4. **✓ 완료·편집**(`Ctrl+Alt+E`) → 편집기에서 설명 수정, 번호 위치 조정, 도형·화살표·모자이크, 화면 자르기, 순서 변경
5. **내보내기**: HTML(단일 파일) / PDF / PowerPoint(PPTX) / JSON

편집기에서 `F1`을 누르면 전체 단축키와 도움말을 볼 수 있습니다.

## 주요 기능

- **클릭 직전 화면을 캡처**해서 "화면이 바뀐 뒤 이전 화면이 찍히는" 문제가 없습니다
- **클릭한 요소를 자동 인식**해 "「저장」 버튼을 클릭합니다" 같은 설명을 자동으로 만듭니다 (오프라인 동작)
- **한 화면에 여러 동작**: 로그인처럼 한 화면에서 아이디 입력 → 비밀번호 → 로그인을 하면 같은 화면에 번호만 추가됩니다
- **편집기 내장**: 도형·화살표·텍스트·이미지·모자이크·부분 확대, 번호 재배치, 화면 자르기, 실행 취소
- **원본 보존**: 번호·주석·자르기는 메타데이터로만 저장되어 언제든 다시 편집할 수 있습니다
- **새 버전 알림**: 새 버전이 나오면 프로그램이 알려 줍니다 (설정에서 끌 수 있습니다)

> **준비 중**: 처음 녹화한 순서를 자동으로 재현해 매뉴얼을 통째로 갱신하는 「녹화대로 다시 만들기」는
> 더 다듬어서 다음 버전에 넣을 예정입니다.

## 개인정보와 보안

- **모든 데이터는 내 PC에만** 저장됩니다. 만든 매뉴얼은 기본적으로 `다운로드\Showhow\<제목>` 폴더에, 설정은 `%LOCALAPPDATA%\ManualMaker`에 들어갑니다
- 녹화 중에는 **화면과 클릭한 요소의 이름, 일반 입력란에 입력한 값**이 기록됩니다.
  비밀번호 입력란의 내용은 읽지 않지만, **화면에 보이는 정보는 그대로 캡처**되니 민감한 화면에서는 ⏸ 일시정지를 사용하세요
- 편집기는 외부 통신을 차단(CSP `connect-src none`)해서, 남이 만든 매뉴얼 파일을 열어도 정보가 새지 않습니다
- 진단 로그에는 요소 이름이나 입력값을 남기지 않습니다
- 인터넷을 쓰는 곳은 **새 버전 확인** 한 군데뿐입니다. 이 저장소에 올려 둔 버전 정보 파일을 받아오기만 하고,
  내 PC나 매뉴얼에 대한 정보는 아무것도 보내지 않습니다. 설정 > 업데이트에서 끌 수 있습니다
